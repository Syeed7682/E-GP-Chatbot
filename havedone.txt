3. CORE SERVICES IMPLEMENTATION (app/services/)
   [x] document_loader.py:
       - Uses 'pypdf.PdfReader' to read PDF manuals page by page.
       - Implemented 'clean_text()' for whitespace normalization and newline formatting.
       - Functions: 'load_pdf()', 'load_all_documents()'.
   [x] text_chunker.py:
       - Implemented 'split_text_with_overlap()' with natural whitespace boundary snapping.
       - Implemented 'chunk_documents()' assigning unique chunk_id, source, page, and text.
       - Implemented 'save_chunks()' and 'load_chunks()' for JSON persistence.
   [x] embedding_service.py:
       - Upgraded to a Full Multimodal Embedding System (supporting both Text and Images).
       - Supports BAAI/bge-visualized-m3 (1024-dim), google/siglip-base-patch16-224 (768-dim), and CLIP.
       - Implemented:
         * 'embed_text(text)' -> 1024-dim normalized vector.
         * 'embed_image(image)' -> 1024-dim normalized vector (supports file path, bytes, or PIL Image).
         * 'embed_multimodal(text, image)' -> Jointly fused 1024-dim vector in shared semantic space.
         * 'embed_chunks(chunks)' -> Automatically computes multimodal embeddings combining section text and portal screenshot.
       - Multimodal fallback: deterministic perceptual image feature mapping + CRC32 text projections into 1024-dim space.
       - Unit-length L2 normalization for exact cosine similarity in FAISS.
   [x] faiss_service.py:
       - FAISS 'IndexFlatIP' implementation for exact inner-product (cosine) search.
       - Implemented 'build_index()', 'save()', 'load()', and 'search()'.
       - Maps FAISS vector IDs directly to document metadata (source file, page number, snippet).
   [x] retrieval_service.py:
       - Glues EmbeddingService and FaissService together.
       - Accepts questions, embeds them, queries FAISS, and formats results.
       - Produces formatted context prompt strings and structured source references.
   [x] llm_service.py:
       - Direct integration with Qwen2.5-VL-72B-Instruct via:
         1. Local Transformers mode (Qwen2_5_VLForConditionalGeneration & AutoProcessor with CUDA / qwen_vl_utils).
         2. Hugging Face Inference API / Client (via HF_TOKEN).
         3. Offline extractive fallback mode.
       - Multimodal support: accepts text questions and optional image inputs (screenshots/diagrams).
       - Loads system prompt from 'app/prompts/system_prompt.txt'.
